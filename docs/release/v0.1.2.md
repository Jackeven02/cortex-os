# v0.1.2 — Cortex

**Documentation only.** No code, no ABI, no CLI surface, no behaviour change —
`0.1.2` is `0.1.1`.

## What changed

Both READMEs now say how to install it. Neither had an install section at all:
they went straight from the CLI demo to Status, and the only install instructions
anywhere in the tree were the `git clone` lines in the publish runbook — while the
package had been on npm since `0.1.0`. A tool with two published versions and no
"here is how you get it" is a documentation gap, not a missing line.

```bash
npm i -g cortex-agent-os     # puts `cortex` and `ctx` on your PATH
cortex help

# or, without installing anything:
npx cortex-agent-os help
```

The new `## Install` / `## 安装` section (same position in both files) also covers
the Node and dependency requirements, the clone-and-run-the-suite path for anyone
working on Cortex itself, and why the npm package is `cortex-agent-os` while the
binary is still `cortex`.
