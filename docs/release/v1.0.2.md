# Cortex v1.0.2

A second packaging patch for the same class of bug: **the bundled demos loaded
for a real `npm i` user only if they used the right Node and typed a path that
did not exist in their directory.**

## The bug (turned out there were two)

`1.0.1` put `examples/` in the tarball. That fixed "module not found" but
exposed a deeper problem:

1. **Node will not type-strip `.ts` under `node_modules`.**
   `cortex spawn --module ./examples/hello-agent.ts` failed with
   `code 127: agent load failed: Stripping types is currently unsupported for
   files under node_modules`. The READMEs' "Node 22.18 type stripping" advice
   was simply wrong here — that path is off-limits to the stripper.

2. **The path was relative to the user's cwd.** The README told npm users to run
   `./examples/<x>.ts`, but after `npm i -g` there is no `examples/` in their
   working directory. The promise "demos work straight after `npm i -g`" was
   never true.

## The fix

- Examples are now **compiled to plain JS** in `dist/examples/`
  (`tsc -p tsconfig.examples.json`, wired into `build`). No type stripping, no
  Node-version caveats — they load on every Node `engines` allows.
- New **`cortex example <name>`** command: it resolves the bundled module
  relative to the *package*, not the cwd, and forwards to `spawn` with the
  demo's default role. No paths to type:
  - `cortex example hello`
  - `cortex example demo-a` (supervision tree)
  - `cortex example demo-b` (checkpoint / reboot)
  - `cortex example demo-c` (fork + diff)
  - `cortex example caps --cap tool:dangerous` (least privilege)
  - `cortex example mcp` (needs `CORTEX_MCP_COMMAND`)
- Both READMEs now point at `cortex example` and drop the inaccurate
  type-stripping workaround entirely.

The `.ts` sources still ship and still work straight from a clone with `tsx`.

## Install

```bash
npm i -g cortex-agent-os
cortex example hello
```

**Requirements:** Node 22+. One runtime dependency (`cborg`). MIT. Smoke:
**525 checks**. No kernel or ABI change — the 1.0 ABI freeze is untouched.
