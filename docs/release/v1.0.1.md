# Cortex v1.0.1

A packaging patch, and an embarrassing one: **the README's demos did not work
for anyone who installed from npm.**

## The bug

`examples/` was deliberately excluded from the published tarball. But every demo
in the README — all three killer demos included — runs
`cortex spawn --module ./examples/<something>.ts`. So `npm i -g
cortex-agent-os`, open the README, follow the first example, and you get
*module not found*.

It also quietly broke our own exit criterion. BACKLOG Phase 4 says "all three
demos can be reproduced by a stranger following the README in under 10
minutes." That was true only if the stranger cloned the repository. For the
person who installed the package — the more common case — it was false.

`examples/` now ships in the package.

## One caveat that shipping them surfaced

The examples are `.ts`, loaded by Node's type stripping. Verified working:

- **Node 22.18+ and 24** — works out of the box.
- **Earlier Node 22.x** — prefix with `NODE_OPTIONS=--experimental-strip-types`.

If you would rather not think about it: `cortex spawn --role coder --task "..."
` needs no `.ts` file at all and exercises the same kernel path.

## Also

README / README.zh-CN said 513 assertions; the suite is 525.

No kernel or ABI change. This is a packaging and documentation patch — the
1.0 ABI freeze is untouched.

## Install

```bash
npm i -g cortex-agent-os
cortex spawn --role demo --module ./node_modules/cortex-agent-os/examples/hello-agent.ts
```

**Requirements:** Node 22+ (22.18+ for the `.ts` examples without a flag). One
runtime dependency (`cborg`, for the syscall log). MIT. Smoke: **525 checks**.
